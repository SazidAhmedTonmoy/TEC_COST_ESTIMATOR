Database backups

The latest Catalog / Estimator and Tenders backups are kept separately. Daily backups are scheduled for 12:10 am server time; deployment installs the scheduled job. Back up now saves both databases. Download a copy to another device for protection against disk failure. Restoring replaces the whole database and signs everyone out.
