# TEC EstiDoc User Guide

Version 3.7.30 · Estimator and Tenders

Open **? Help → User Guide** inside the website to search these instructions.

## Getting started

### Sign in and choose a homepage

1. Sign in using your assigned account. If prompted, change the temporary password first.
2. Choose Estimator or Tenders from the workspace switcher. Both use the same account.
3. Open My Profile to choose your own preferred homepage; Auto follows your role/team default.

**Tip:** Your administrator manages accounts, team access and permissions.

### Find your way around

1. Use the sidebar to open the features in your current workspace.
2. Use the Estimator / Tenders switcher to change workspace without signing out.
3. Use search in the relevant register to find a project by name, builder or reference.
4. Use Help → User Guide for step-by-step instructions or Help → AI Assistant for a question.

**Tip:** Opening a project should not force you to recreate a search or filter.

### My Profile, photo and security

1. Click your profile in the sidebar and edit your name, contact details and job title.
2. Upload a profile photo or select initials. Choose My homepage.
3. Enter the current password when changing your username or password, then save.

**Tip:** A password change signs out other sessions. Do not share passwords with Help.

## Estimator workspace

### Estimator Home and Project Board

1. Use Home for project status, assigned activity, deadlines and the Project Board.
2. Search all accessible projects with the top search box, regardless of selected month or status.
3. Open an estimate from its project card; use Details & actions for additional project operations.
4. Administrators can review team activity with selectable week or month.

**Tip:** Closed estimates are not counted as submitted/completed estimates.

### Create and set up an estimate

1. Select New Project. Enter the project name, builders, team and submission deadline.
2. Open the project, then set labour rate, working hours/day, crew size and mark-ups.
3. Use Manage project & activity to update its brief, team assignments and workflow.

**Tip:** Changes to costing settings affect project calculations; check totals before exporting.

### Project progress and deadlines

1. Use the Progress dropdown beside Estimate Setup guide.
2. Choose Not started, In progress, In review, Submitted or Closed as appropriate.
3. In review requires a review deadline. Submitted represents an estimate that has been submitted.

**Tip:** Closed may mean discarded work; it is not automatically a completed estimate.

### Add catalog items to an estimate

1. Search the reusable Catalog from the Estimate page.
2. Inspect the item, specification, materials and labour build-up before adding it.
3. Use Add to estimate, set the project quantity and adjust any project-only reference or price.

**Tip:** Changes to a project snapshot do not automatically change the master Catalog.

### Edit estimate items and components

1. Expand the relevant category to show its estimate items.
2. Edit quantity, reference, item description, remarks and project-only supply price as needed.
3. Use Edit item to inspect component quantities, material prices and labour hours.
4. Drag the dotted handle to reorder items or categories; use Expand All / Shrink All.

**Tip:** Fixed-quantity components do not scale with the parent quantity.

### Yellow and red item highlights

1. Click the highlight marker beside an item once for yellow, twice for red, then again to clear.
2. Highlights are stored with the estimate and can be viewed by other authorized users.
3. Read-only viewers can see markers but cannot change them.

**Tip:** Highlight colours do not affect the estimated price.

### Materials, labour and quoted total

1. Check project material mark-up, labour rate, labour-hour mark-up and final mark-up.
2. Review material totals, labour hours, labour cost and included quoted total.
3. Optional categories are excluded from the included quoted total.
4. Use the crew plan for approximate person-days and working-days calculations.

**Tip:** The application estimates costs; verify supplier quotes and project-specific assumptions.

### Activate and use Breakdown

1. Open Breakdown from an estimate and choose Active. It stays active until an editor switches it off.
2. Add Area / Floor / Space names and choose Allocation or Structured View.
3. Find items with Breakdown search by name, reference, remarks, category or area.
4. Changes autosave. Use Undo / Redo if a distribution is incorrect.

**Tip:** When inactive, Breakdown sections are omitted from Excel and public share views.

### Allocate quantities to areas

1. Select Single area for an item assigned entirely to one area.
2. Select Multiple areas to divide quantity between several spaces; enter quantities or distribute equally.
3. Use a common-to-all-areas option only for items intended as a shared allowance.
4. Check Remaining and the unallocated-only filter before finishing.

**Tip:** The breakdown divides the existing estimate quantity; it must not increase project totals.

### Save, view and compare revisions

1. Open Revisions in an estimate and save a snapshot at an appropriate milestone.
2. Use View to inspect a saved snapshot without changing the live estimate.
3. Use Compare to see differences against another revision or the working estimate.
4. Restore a revision only when you intend to replace the working state.

**Tip:** Check the revision date, label and totals before restoring.

### Notes, contributors and activity

1. Use Add Note to record assumptions, clarifications and decisions.
2. Use Manage project & activity to inspect the project journey, permissions and history.
3. Read activity and revisions before changing an estimate another colleague is editing.

**Tip:** Edits and notes are attributed to the signed-in account.

### Export Excel and share an estimate

1. Review included and optional totals, references, remarks and active Breakdown allocations.
2. Choose Export Excel to generate the estimate workbook.
3. Use Share to generate a read-only project view according to its sharing settings.

**Tip:** Sharing or exporting does not give the recipient permission to edit the project.

## Catalog, Light Price and imports

### Catalog Explorer

1. Open Catalog and search item titles, codes, components or categories.
2. Inspect component material price, hours and installation type in the details panel.
3. Add to estimate for a project snapshot, Edit catalog item for the reusable record, or Save as new version when appropriate.
4. Use Source history to trace imported sheets and workbook occurrences.

**Tip:** Catalog prices may be historical; confirm current supplier pricing.

### Light Price library

1. Open Light Price and search by supplier, catalogue number, description, project or nickname.
2. Inspect individual components, included/excluded items and connected unit cost.
3. Use supplier quotations as pricing references, not automatically current offers.

**Tip:** Quoted supplier prices are generally AUD excluding GST.

### Import an estimating workbook

1. Open Import and select the workbook upload/preview tools.
2. Check the detected sheet structure and warnings before committing an import.
3. Review the import summary and source history afterward.

**Tip:** Avoid importing a live database file as a workbook.

### Import supplier lighting prices

1. Open Import → Add supplier prices.
2. Check the quotation, review detected fittings and component pricing, then import selected records.
3. Inspect changed or duplicate quotes before approving an update.

**Tip:** Scanned PDF quotations may need a text-readable copy or OCR before extraction.

## Tender workspace

### Tender dashboard and pipeline

1. Use Dashboard for total projects, live submission pipeline, builder outcomes, pricing feedback and follow-ups.
2. Open Project Chase-up for detailed filters and the complete submission register.
3. Select a chart segment to view related submissions.

**Tip:** TEC Won and Builder Awarded are different outcomes.

### Create and edit a tender

1. Select New tender, complete project, builder, deadline, region and quotation details.
2. Save the submission and open it to add chase-up history or modify outcomes.
3. Use editing menus rather than Delete for routine corrections.

**Tip:** Keep tender status, builder result and pricing feedback distinct.

### Multi-select filters, search and saved context

1. Open the Filters panel in Project Chase-up, Projects or Builders.
2. Tick multiple options in Region, TEC status, Team, Builder outcome and other fields.
3. Values within one field use OR; different fields combine using AND.
4. Clear a field or use Clear filters to start over.

**Tip:** Filters should stay in place when opening a tender and returning to the register.

### Open-Awarded builder projects

- Each awarded builder can have **multiple contact people**, and each person can have **multiple phone numbers and email addresses**. Use **Edit** on the awarded card, then **Add contact person**, **Add phone** or **Add email**. Remove entries before saving as needed. The Card, Calendar contact panel and Tender Details view show the saved contacts. Every number opens the device dialler and each email opens Outlook web compose. Existing single contacts are retained.

1. Open **Tenders → Open-Awarded**. The page shows builder submissions where the TEC quotation is **Open** and the builder outcome is **Awarded**.
2. In **Cards** view, each project shows the builder, awarded date, **estimated start date**, submitted value, project link (when available), last chase-up and awarded-project contact. Projects are sorted by the recorded award date, newest first; missing award dates appear last.
3. Switch to **Calendar** view to see **Awarded** dates in amber and **Est. start** dates in teal. Navigate months with the arrows or month picker. Select a date or calendar event to show its project, builder and contact information in a panel below the calendar. Phone numbers call through your dialler; email opens Outlook. Use **View project** for the complete history. Undated events are never guessed or shown on the calendar.
4. Choose **Add contact** (or **Edit**) on the card or calendar event panel to record dates, the optional project URL and multiple contacts. For each person, use **Add phone** or **Add email** to record more than one. Partial records can be saved, with missing details clearly marked.
5. **Project link** is filled automatically from a linked Opportunity. Where there is no formal link, an exact unique Project + Builder + Region match can suggest the Opportunity's URL. Ambiguous matches are never selected automatically. To use a different URL, enter a manual override; clear it to use the Opportunity URL again.
6. Select a phone number to open your device dialler or an email to compose in Outlook on the web (a signed-in Microsoft 365 account may be required). Click a card, or **View project** in the calendar event details, to open full Tender details and chase-up history.

**Tip:** Original tender contacts and underlying opportunity links are not overwritten by Open-Awarded edits. Dates are entered by your team, not inferred from deadlines or chase-ups.

### Project Chase-up and follow-up history

1. Open Project Chase-up and find a submission by project or builder.
2. Record contacts, follow-up notes, dates and any promised next action.
3. Schedule the next chase-up and review reminders when due.

**Tip:** Chase-up history retains its author; do not overwrite a colleague’s record to add a new contact.

### Projects and Builders registers

1. Use Projects for grouped project totals across builders.
2. Use Builders to compare builders’ submissions, wins and values.
3. Open a group to examine its connected quotations.

**Tip:** Project value may use the highest builder quote; builder submissions remain separate.

### Calendar, deadlines and reminders

1. Open Calendar for upcoming submission deadlines, follow-ups and approved opportunities.
2. Switch Month / Agenda where available and move to the required date.
3. Use Reminders to review due and completed follow-ups.

**Tip:** Notifications may require browser permission; in-app reminders do not.

### Import and export tender registers

1. Use Import Excel in Tenders to preview and merge new or changed submission rows.
2. Check duplicate matches and merged builder records before proceeding.
3. Use Export to download the currently selected register results.

**Tip:** Back up the live database before major imports.

### Opportunities and approvals

1. Open Opportunities and add a project with its address, builder, deadline and scope.
2. Review incoming opportunities, assign an authorized team and approve or reject.
3. Use Approved → Need to quote to find approved projects awaiting a quotation.

**Tip:** Opportunity approval is separate from submitting an electrical quotation.

### Create an estimate from an approved opportunity

1. Open an Approved opportunity and go to Project Journey → Estimator project.
2. Choose Create Estimate if your assigned team has Estimator access, or link an existing estimate.
3. Check the copied project brief, builder, deadline and team before pricing.

**Tip:** This operation is permission-checked and prevents duplicate links.

### Record quotations and outcomes

1. In an Approved opportunity, choose Quoted or Not quoted as appropriate.
2. Connect a quoted opportunity to the corresponding Tender project or Chase-up record.
3. Update the builder’s actual award outcome separately from TEC’s quote result.

**Tip:** Do not treat builder award status as proof TEC won the work.

### Opportunity analytics

1. Open Opportunities → Analytics to view created, approved, pending quotation, rejected and expired counts.
2. Select month, month-by-month, custom dates or All time.
3. Use Original added date versus Upload/creation date when reconciling imported Excel opportunities.

**Tip:** All signed-in active users can view Analytics; counts use the selected date source.

## Teams, administration and safety

### Accounts, teams and editing access

1. Administrators open Manage Users to add users, manage roles and team memberships.
2. One account may belong to multiple teams. Team assignment controls access to relevant estimate editing.
3. Each team can have its own default homepage and Estimator usage setting.

**Tip:** Do not share admin credentials. Viewer access and edit access are different.

### Settings, AI configuration and backups

1. Administrators open App Settings to configure supported application options and Gemini access.
2. Confirm integrations before submitting private workspace records or documents to an external AI provider.
3. Use database backup/restore controls carefully; restoring a backup replaces newer data.

**Tip:** Your application has separate Estimator and Tender SQLite databases; protect both.

### AI Assistant, documents and confirmed actions

1. Open ? Help → AI Assistant to ask about an estimate, project, catalog item or tender.
2. Use the attachment button to supply a text PDF, spreadsheet, DOCX or text file.
3. Enable configured Gemini in Help Settings if you want AI-powered analysis using supplied context.
4. For supported write tasks, such as adding a note, updating project progress, changing a deadline, recording Won/Lost or renaming a project, review the preview and select Confirm.

**Tip:** The assistant cannot arbitrarily access external systems, ignore user permissions or execute unknown operations. Actions require approval.

### Saving, retry and recovery

1. Watch Saved / Saving / Unsaved status in Estimator and Breakdown.
2. If a write fails, do not repeat it blindly: first verify whether the server saved the change.
3. Use revisions, Undo/Redo or authorized backup recovery for mistakes.

**Tip:** When your connection is interrupted, keep the page open until you have verified the saved state.
